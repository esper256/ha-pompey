# Household acceptance

Pompey should turn a Seerr request into correctly routed media for a separate Plex installation, preserve unexpected files, honor sharing choices, keep internet behind the VPN, and explain blocked requests.

The [integration foundation](foundation.md) implements the architecture for fresh amd64 installations and begins with one fully real movie journey. [Testing](testing.md) states the current proof and outstanding scenarios. Do not equate that first scenario with complete household coverage, Supervisor validation or Plex playback.

Cold HA backups provide recovery. The automated suite is the release authority as coverage expands; manual HAOS acceptance is no longer a required release gate.
