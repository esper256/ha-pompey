# Pompey (the Home Assistant app)

The household guide is the [root README](../README.md). This folder is what Supervisor builds.

**0.2.26** is the current cut on a real Home Assistant OS machine. Sidebar is Pompey (Proton, status, Open search, Open sources). Search is Seerr on port 5055. Sources are Prowlarr on port 9696. Plex is a separate app. Media folders are Home Assistant options (defaults match this house). Auto-grab prefers 1080p WEB-DL/BluRay encodes over remux/4K. The app log tags every hidden service and copies qBittorrent’s file log into it. See the README for the intended journey, what is not ready, and the roadmap.
