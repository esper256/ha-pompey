# Pompey

Home Assistant app for the whole stack. The household search UI is Seerr; Pompey is the box around it: Proton, kill switch, hidden engines, no extra consoles.

**0.2.0 is experimental.** What is actually done vs not — and whether to install on Home Assistant yet — is in the [root README](../README.md). Short answer: **not for household use**; only try HAOS if you want to report breakage.
