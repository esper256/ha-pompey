# Pompey

Home Assistant app for the whole stack. The household search UI is Seerr; Pompey is the box around it: Proton, kill switch, hidden engines, no extra consoles.

**0.2.11 is meant for a first Home Assistant OS try** if you have Proton, a Plex IP, and a source. See the [root README](../README.md) and [DOCS.md](DOCS.md). It is not a finished household app.
